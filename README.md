# TaskFlow – To-Do List Web App

TaskFlow is a simple and responsive task management web application built using HTML, CSS, and JavaScript. It allows users to organize their daily tasks, track their progress, and manage completed and pending tasks through a clean dashboard interface.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Track total, completed, and remaining tasks.
- View task completion progress.
- Save tasks using browser Local Storage.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Application functionality and DOM manipulation.
- Local Storage – Saving tasks in the browser.
- Lucide Icons – Modern interface icons.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/RoseIbrahim1/taskflow.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
